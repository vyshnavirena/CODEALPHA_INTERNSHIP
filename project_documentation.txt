BASIC NETWORK SNIFFER
PROJECT DOCUMENTATION

1. INTRODUCTION

A network sniffer is a tool used to capture and analyze network packets. This project implements a basic network sniffer using Python and Scapy.

2. OBJECTIVE

The objective of this project is to capture network packets and display important information such as source IP, destination IP, protocol, ports, packet size, and timestamp.

3. TECHNOLOGIES USED

* Python
* Scapy
* Visual Studio Code
* Windows

4. MAIN FEATURES

* Capture all IP packets
* Capture TCP packets
* Capture UDP packets
* Capture ICMP packets
* Display source IP address
* Display destination IP address
* Display protocol
* Display port information
* Display packet size
* Display timestamp
* Generate a capture report
* Identify selected suspicious ports

5. WORKING

The user starts the Python program and selects a packet capture option. Scapy then captures matching IP packets. The program analyzes each packet and extracts its source IP, destination IP, protocol, ports, and packet size. The information is displayed on the terminal and stored in capture_report.txt.

6. TESTING

TCP packet capture was successfully tested.

UDP packet capture was successfully tested.

All-packet capture was successfully tested.

ICMP capture was tested, but ICMP packets were not detected during the current testing environment.

7. OUTPUT

The captured packet information is stored in capture_report.txt.

The report includes:

* Timestamp
* Source IP
* Destination IP
* Protocol
* Ports
* Packet size
* Alert status
* Capture summary

9. CONCLUSION

The Basic Network Sniffer successfully demonstrates packet capture and basic network traffic analysis using Python and Scapy. The project provides a foundation for developing more advanced network monitoring and security tools.
